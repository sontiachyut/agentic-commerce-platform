# ADR 005 — Narrow business tools and project-specific contracts first

**Status:** proposed. Expose search/quote/approval-request/approved-execution/status through fixed typed authorized tools; no raw financial/dispense/SQL/URL/signing capability. Backend revalidates immutable terms and current policy regardless of model behavior.

AP2 informs authority, Medusa commerce and LangGraph workflow. UCP/ACP/TAP adapters require actual interoperability demand and pinned conformance; none is initial wire protocol. Avoid multiple agents, MCP services, vector search or external registries merely for a diagram. Consequence: smaller safe inspectable demo with explicit limits and later adapters. AC-09/10 evaluate model susceptibility separately from backend enforcement. A valid tool schema or authenticated agent is not authorization.
