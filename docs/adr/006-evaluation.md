# ADR 006 — Deterministic correctness and probabilistic quality have separate scores

**Status:** proposed. Hidden scenario oracle labels valid product set, approval/policy, source effects and unknown outcomes. Keep visible evidence separate; split scenario families; compare rule/fixed workflow to bounded agent. Model/provider/prompt versions and failed runs remain in records.

Single polished demo, all-abstain behavior or model judging its own answers cannot establish task quality. Hard gates concern actual unauthorized/duplicate effects and false success; model invalid proposals, preference accuracy, recovery, latency/cost are separately reported. No fabricated benchmark or unsupported production claim. Real-provider runs require usage approval and finite budget. Keep simpler workflow if added agent cost/latency has no demonstrated benefit.
