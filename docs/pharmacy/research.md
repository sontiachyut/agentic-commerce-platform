# Pharmacy and voice workflow research

Reviewed 2026-11-04. Public primary sources inform workflow boundaries; they are not code or interface designs to reproduce.

| Evidence | Product consequence |
| --- | --- |
| [CVS family prescription management](https://www.cvs.com/retail/help/help-subtopic-family-prescription-management) and [prescription management](https://www.cvs.com/retail/help/help-subtopic-prescription-management) describe authorization for adult caregiver access | Store explicit per-person access separately from purchasing permission. Recheck it before reservation and pickup; do not infer it from “my dad.” |
| [Walmart family management](https://www.walmart.com/help/article/manage-family-prescriptions/24136f772ce54ebfa33e30a4c38e4273) similarly requires adult approval | Household membership is not authorization. Include a revoked-access scenario. |
| [CVS refill service](https://www.cvs.com/content/refill) describes refill schedules, prescription processing and prescriber renewal when refills run out | Existing refills, prescription renewal and ready-for-pickup are separate facts. The first product requests eligible saved items; it does not fabricate a prescription or renewal. |
| [Walmart prescription status](https://www.walmart.com/help/article/prescription-status-and-pharmacy-refill-orders/2c0ae420ce6a4ab2b19e4a8ec78cf095) separates requests, status and pickup location | Expose customer order status and facility handoff, rather than a generic immediate-delivery confirmation. |
| [HL7 FHIR R4 MedicationDispense](https://hl7.org/fhir/R4/medicationdispense.html) distinguishes preparation and handover information | Keep preparation/readiness/handover separate in the domain. This is conceptual guidance, not an implemented FHIR interface or conformance claim. |
| [Apple CarPlay overview](https://developer.apple.com/carplay/) includes voice-based conversational apps; [entitlements](https://developer.apple.com/documentation/carplay/requesting-carplay-entitlements) require review/managed capability | A browser voice demo is feasible now. It is not native CarPlay. Preserve a voice-oriented service API for a future approved native client. |
| [whisper.cpp](https://github.com/ggml-org/whisper.cpp), release v1.9.5 at d1be6fde11ac6e0407606b4e42fe72d34add8037, provides local speech recognition | Use a separately provisioned, pinned local executable and model. Do not need a billable transcription service. |
| [Official whisper.cpp model conversion repository](https://huggingface.co/ggerganov/whisper.cpp) lists tiny.en at approximately 75 MiB | Validate recognition using the real request, retain actual timing/error evidence, and support text fallback. Model size is not proof of medication-name accuracy. |

CVS pages timed out on direct tool fetch; their indexed primary-page text was available. The accessible Walmart pages provide a second direct account-management/status reference. No claim relies on anonymous forum speculation. Synthetic patient eligibility, prices, hours and inventory in the product are authored fixtures, not assertions about either retailer's actual operations or pricing.

No real patient data, live prescription fulfillment, insurer payment or clinical advice is part of this local release. Pharmacy-specific legal/regulatory obligations for a real deployment have not been assessed or certified. A client integration must supply its approved authorization, clinical, pricing and operational contracts.

## Natural voice selection — owner request 2026-11-04

The owner explicitly requested current natural, human-like speech rather than the default system voice. The selected optional profile is [Qwen3-TTS](https://github.com/QwenLM/Qwen3-TTS) with the [MLX Community 0.6B CustomVoice 8-bit conversion](https://huggingface.co/mlx-community/Qwen3-TTS-12Hz-0.6B-CustomVoice-8bit) and MLX Audio 0.6.4 on Apple Silicon. The original model and conversion list Apache-2.0. Use supplied Ryan/Aiden presets; no person's voice is cloned. Model revision, every downloaded file's SHA-256 and the separate hashed dependency lock are committed. Weights and optional environment remain ignored locally. Inference uses local paths with Hugging Face/Transformers offline mode.

Alternatives reviewed: [Kyutai Pocket TTS](https://kyutai.org/tts/) targets CPU/streaming use, but its current model repository is gated behind owner-account acceptance; we did not bypass that gate. [Supertonic](https://github.com/supertone-oss-archive/supertonic) has useful local ONNX models but its upstream archive says development/support ended, so it was not chosen as the new maintained default. [Chatterbox](https://github.com/resemble-ai/chatterbox) offers expressive generation; Qwen's supplied voices and Apple Silicon runtime fit this machine's current integration path. These are engineering fit decisions, not a claim that one voice is objectively best.

The 0.6B Qwen variant supports preset voices but not the larger model's instruction/style-control feature. This implementation does not advertise voice design/cloning, emotional instruction control or universal platform support. Naturalness is a listening judgment: provide a generated sample and the actual client video for review. Recognition, synthesis and end-to-end latency must be measured separately; model-card performance on another machine is not our benchmark.
