# Asterfield Family Pickup — product demonstration

[**Watch / download the complete 3m57s video**](https://raw.githubusercontent.com/sontiachyut/agentic-commerce-platform/main/docs/demo/family-pickup-demo.mp4)

The MP4 is committed in this repository alongside its [captions](family-pickup-demo.srt), [customer screenshot](customer-order.png), [pharmacy screenshot](pharmacy-desk.png) and [checksum manifest](manifest.json). GitHub's README player provides a second convenient viewing copy when available.

The recording shows a $35 budget stop, then a spoken request for four family members under a separately configured $50 permission. The complete $40.98 basket is accepted at Cedar Square, prepared by pharmacy staff, charged, marked ready and collected using the customer pickup code.

All people, prescription records, prices, locations, payments and handovers are synthetic. The customer command and narration use supplied Qwen3-TTS neural voices. The real recorder, local speech recognition, actual Codex interpretation, persistent backend, source simulator and staff workflow run without mocked network responses. Actual app spoken updates are included in the soundtrack.

See [the full walkthrough and capture recipe](../pharmacy/demo-guide.md) and [sanitized run evidence](../../results/pharmacy/2026-11-04-local.json). The original WebM, raw synthetic audio and detailed scene/request artifacts remain private debugging/reproduction material, outside the public repository.
